## 2. 必补边界

| ID | 检查内容 | 失败时处理 |
|---|---|---|
| R-01 | 跨 Group 组合、多候选排序、已有对子、连续结算、同一输入多次胡牌（合法白盒可达时） | 修规则，不锁死推荐路线 |
| R-02 | 7+2 可救与不可救；稳定满七且无槽内候选立即 Lost（不取决于桌面能否救牌）；未满无步仅 Stalled；未知/旧局/重复输入 | 不扩大失败规则 |
| R-03 | 只取最高番、杠第四张花色、破坏组不合格、目标不足/零目标、跨快照无重复目标 | 冻结目标并比对手工期望 |
| R-04 | 提交前异常回滚；提交后监听异常不回滚、其他订阅继续；重入 busy | 保留失败证据，修事务边界 |
| R-05 | 固定 48/32/16、牌面≤4、遮挡图无环、初始可点 B01～B10、相同命令回放一致 | 拒绝非法配置，不偷偷换布局 |
| R-06 | 重开与大招并发、重复事件、旧 session、终局残视觉、结果面板最长等待 | 取消/超时清理而非卡局 |
| R-07 | 同一 GameSession 连续重开20次仍可 dispatch；场景级订阅只保留一份，旧 Round/Effect Scope 清零；退场才 dispose 控制器 | 不因重开关闭长期控制器或重复订阅 |

## 3. V2 白膜表现与物理

| ID | 通过标准 |
|---|---|
| V-01 | 全部 UI 用 2D；720×1280 基准及短屏/长屏安全区无按钮遮挡；牌桌无 3D 透视场景 |
| V-02 | 真实 Mesh 牌块有厚度；引擎 Label 清晰展示万/筒/条及数字；双块两字面共一实体 |
| V-03 | 三相机/Layer 色块探针正确叠加；没有背景覆盖牌、UI 重复绘制、下层字透上层白膜；逐查 B05/B11 重叠处 |
| V-04 | 设计点→世界/屏幕/UI 往返误差 ≤1 设计像素；触摸块中心/边缘、 resize 后仍一致，不能把物理 hit 当遮挡规则 |
| V-05 | 正常档 Web、微信工具、真机可观察 Box 刚体反弹/翻转；一个双块一个刚体，不以 2D 缩放替代 |
| V-06 | 动态替身≤12；最多 5 组大招完整处理，叠加超限执行已定义视觉降级；对局结果不因物理参数变化而变 |
| V-07 | 重开/退出/前后台/超时/视觉异常后刚体和监听清理，旧效果不出现在新局；不卡输入 |
| V-08 | 正常长按/滑动/多指/重复触摸不误发多命令；被遮挡/终局不能取牌；重开不受动画锁 |
| V-09 | 白膜、纯色材质、引擎文字，不含正式美术/外部依赖；入局前预建、点击不创建新材质或请求加载 |
| V-10 | 目标机稳态帧 p95≤33.3ms 的工程目标有采样，记录 draw call/物理峰值/资源趋势；超预算先报告优化，不能只报桌面数字 |
